# PatientTracker-MCA

Browser-based Hospital & Clinic Management Web Application built using **HTML5, CSS3, Vanilla JavaScript, and JSON (`localStorage`)**.

## Project Modules & Branches
- `module-login` (`login/`): Login, Session, Navbar, Admin & Clerk Front-Desk, Medicine Stock & Billing (Roll Nos. 01–18)
- `module-doctor` (`doctor/`): Doctor Dashboard, Patient Lookup, Consultation Entry, E-Prescription Builder, Printable Rx & Patient Feedback (Roll Nos. 19–36)
- `module-patient` (`patient/`): Patient Consultation History, Rx Details, Daily Dosage Schedule, Health Feedback & Billing Receipts (Roll Nos. 37–54)
